# Workflow: จากของจริง → ไฟล์ปริ้น → Bambu Lab P2S

## เครื่องมือที่ควรมี

- **เวอร์เนียคาลิปเปอร์ดิจิทัล** (อันละไม่กี่ร้อยบาท คุ้มสุดในบ้าน) —
  หัวใจของงาน true-to-scale คือการวัดของจริงให้แม่น
- Python + PartKit (repo นี้)
- Bambu Studio (ฟรี)

## ขั้นตอน

### 1. วัดของจริง

- **รู/แกน**: วัดเส้นผ่านศูนย์กลางจริง อย่าเดา — สกรู "M4" บางตัววัดได้ 3.9 mm
- **ระยะรูสกรู**: วัดจากศูนย์กลางถึงศูนย์กลาง (วัดขอบถึงขอบใกล้ + ขอบถึงขอบไกล
  แล้วหาร 2 จะแม่นกว่า)
- **ช่องที่ชิ้นงานต้องสวมเข้า**: วัดขนาดช่อง แล้วปล่อยให้ PartKit คิดค่าเผื่อ —
  อย่าลดขนาดเองในหัว จะงงว่าเผื่อไปแล้วหรือยัง

### 2. แก้พารามิเตอร์แล้ว generate

```bash
python parts/spacer.py --inner-dia 8.0 --outer-dia 16 --height 5 --fit slide
```

ระบุ "ขนาดของจริง" เสมอ (เช่นแกน 8.0) แล้วเลือกความแน่นด้วย `--fit`:

| fit | clearance/ด้าน | ใช้เมื่อ |
|---|---|---|
| `press` | 0.05 mm | อัดแน่นถาวร ต้องกดแรง |
| `tight` | 0.10 mm | ดันเข้าด้วยมือ ไม่หลุดเอง (แกนลูกบิด) |
| `slide` | 0.20 mm | สวม-ถอดคล่อง ไม่โยก (ฝากล่อง) |
| `loose` | 0.30 mm | ขยับอิสระ (บานพับ) |

### 3. เข้า Bambu Studio

1. ลากไฟล์ `out/*.3mf` (หรือ `.stl`) ลงหน้าจอ — ขนาดจะตรง mm อัตโนมัติ
   **ห้ามกด scale เด็ดขาด** ถ้าขนาดไม่ตรงแปลว่าพารามิเตอร์ผิด กลับไปแก้ที่โค้ด
2. จัดวางให้ด้านเรียบใหญ่ลงเตียง (แม่แบบใน repo นี้ออกแบบให้ Z=0 คือด้านวางเตียงแล้ว)
3. ค่าปริ้นแนะนำสำหรับชิ้นส่วนใช้งานจริง:
   - วัสดุ: **PETG** (เหนียว ทนร้อน) หรือ PLA ถ้าใช้ในร่มไม่รับแรงมาก
   - Wall loops: **4** ขึ้นไป (ความแข็งแรงมาจากผนัง ไม่ใช่ infill)
   - Infill: 25–40% (grid/gyroid)
   - Layer height: 0.2 mm

### 4. ปริ้นชิ้นทดสอบก่อน (ชิ้นใหญ่/สวมพอดี)

ถ้าชิ้นงานต้องสวมพอดี ให้ตัดปริ้นเฉพาะส่วนสวมสั้น ๆ ก่อน (เช่น spacer สูง 2 mm)
เพื่อเช็ค fit — เสียเวลา 5 นาที ดีกว่าปริ้น 3 ชั่วโมงแล้วคับ

### 5. จูนค่าเผื่อของเครื่องตัวเอง

เครื่อง/เส้นแต่ละม้วนหดไม่เท่ากัน ถ้าพบว่ารูคับหรือหลวมเป็นประจำ
แก้ค่ากลางที่ `partkit/fdm.py` ได้เลย:

- รูคับตลอด → เพิ่ม `HOLE_COMP` (เช่น 0.2 → 0.25)
- ฝากล่องแน่นไป → เพิ่ม `FIT_SLIDE`

แก้ครั้งเดียว มีผลทุกชิ้นที่ generate หลังจากนั้น — นี่คือข้อดีของ code-CAD
